# TechSpace — двухстраничный сайт

- `index.html` — главная страница.
- `about.html` — вторая страница «О проекте».
- `style.css` — общий файл стилей для обеих страниц.

Откройте `index.html` в браузере. Проверьте переход на страницу «О проекте», затем вернитесь на главную через меню или кнопку. Обе страницы подключают один и тот же `style.css`.
