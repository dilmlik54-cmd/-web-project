# TechSpace — Мир технологий

## Название проекта
TechSpace

## Назначение сайта
Сайт предназначен для знакомства пользователей с современными технологиями, искусственным интеллектом, программированием и компьютерной техникой.

## Целевая аудитория
- Школьники
- Студенты
- Начинающие программисты
- Любители технологий

## Используемые технологии
- HTML5
- CSS3

## Структура проекта
- `index.html` — главная страница сайта.
- `style.css` — оформление и дизайн сайта.
- `README.md` — описание проекта.
- `.gitignore` — список файлов, которые не нужно добавлять в Git.

## Как открыть сайт локально
1. Скачайте или распакуйте папку проекта.
2. Откройте папку `TechSpace`.
3. Дважды нажмите на файл `index.html`.
4. Сайт откроется в установленном браузере.

Для работы сайта не требуется установка дополнительных программ. Для отображения фотографий необходимо подключение к интернету.
